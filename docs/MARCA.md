# Marca — Jardim Harmonia Canoas

Não há manual de marca. Os valores abaixo saíram das 4 versões do logo
entregues. Este arquivo é a fonte da verdade do `globals.css`.

## Cor

| Token | Hex | Origem |
|---|---|---|
| `--verde` | `#026938` | logo principal |
| `--verde-escuro` | `#172f1b` | logo versão escura |
| `--areia` | `#d7cbae` | logo versão clara |
| `--tinta` | `#1d1d1b` | logo versão preta |

Tokens de apoio criados para a interface (não vêm do logo):

| Token | Hex | Uso |
|---|---|---|
| `--areia-clara` | `#f4efe4` | fundo de respiro |
| `--tinta-suave` | `#4a4a45` | texto secundário |
| `--erro` | `#b42318` | mensagem de erro do form |

## Logo

Arquivos em `public/img/logo/`:

- `logo-verde.svg` — sobre fundo claro
- `logo-verde-escuro.svg` — sobre fundo claro / areia
- `logo-areia.svg` — sobre fundo verde ou verde-escuro
- `logo-preto.svg` — aplicações monocromáticas

Símbolo: casa com telhado duplo + árvore com folhas, sobre linha de chão.
Só use os arquivos entregues. Não redesenhe nem mude proporção.

## Tipografia

Plus Jakarta Sans em títulos e texto (escolhida no protótipo), servida
pelo próprio site via `next/font`.

## Símbolo

`simbolo-verde.svg` e `simbolo-areia.svg` são o mesmo SVG do logo com o
`viewBox` recortado só na casa + árvore. Usados no header.

## Apoio

`--ipe` #e2b53e (acento amarelo), `--noite` #0f1f12, `--papel` #f7f6f1.
